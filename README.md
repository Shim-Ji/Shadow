# 세상에서 가장 귀한 이야기 · 그림자극 연습 도구

그림자 무언극 '세상에서 가장 귀한 이야기'를 연습하는 배우, 소품 담당, 감독을 위한 사이트입니다.
참고 영상: https://www.youtube.com/watch?v=EDrTKwqpuQY

## 기능
- **전체 구조**: 13개 장면 아코디언 (가사, 무대 배치, 배역별 동작, 소품, 감독 메모)
- **내 역할**: 배역별 동작만 시간순으로 보기. `/?role=p2`처럼 배역 전용 링크 공유 가능
- **전체 흐름**: 배역별 등장 타임라인과 줄거리
- **소품**: 준비물 체크리스트
- **가사 외우기**: 전체, 초성 힌트, 가리기 모드. 줄 단위 반복 재생

배역 이름, 체크, 메모는 각 기기의 브라우저(localStorage)에만 저장됩니다.

## 내용 수정
장면, 가사, 동작, 소품 데이터는 모두 `lib/data.ts` 한 파일에 있습니다. 시간 단위는 초입니다.

## 실행
```bash
npm install
npm run dev   # http://localhost:3000
```

## 배포 (Vercel)
GitHub에 올린 뒤 Vercel에서 저장소를 Import하면 됩니다. 별도 설정이나 환경 변수는 필요 없습니다.
또는 `npx vercel`로 바로 배포할 수 있습니다.
